# Learning paths: content format

Paths live in `content/paths.json`. The site reads them at startup. Check a change with:

```
python scripts/validate_paths.py
```

## Rules

1. Content comes from the team, a mentor or approved sources. Nothing in a path is generated by the AI.
2. Never type a verse or a hadith. Use a `quran` block (surah and ayat) or a `hadith` block (HadeethEnc record id). The site shows the official text from the database. `validate_paths.py` runs our verifier over every `text` block and fails if it finds a typed verse or hadith.
3. A path is shown only when `"status": "published"`, after review by the Sharia mentor. Use `"draft"` while writing.
4. Islamic-law lessons explain general rules from approved material. They never give a personal ruling (levels C and D).

## Structure

```json
{
  "paths": [
    {
      "id": "unique-id-latin",
      "title": "عنوان المسار",
      "description": "وصف قصير",
      "level": "مبتدئ",
      "status": "draft",
      "sources": ["where the content comes from"],
      "modules": [
        {
          "id": "module-id",
          "title": "عنوان الوحدة",
          "lessons": [
            {
              "id": "lesson-id",
              "title": "عنوان الدرس",
              "blocks": [
                {"type": "text", "body": "فقرة يكتبها الفريق."},
                {"type": "quran", "surah": 2, "ayah_from": 1, "ayah_to": 5},
                {"type": "hadith", "record_id": "5913"},
                {"type": "question", "prompt": "سؤال؟", "options": ["أ", "ب", "ج"], "answer": 0},
                {"type": "check", "body": "نص متداول ليجرّبه المتعلّم في أداة التحقق"}
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

| Block | Fields | Shown as |
|---|---|---|
| `text` | `body` | A paragraph. |
| `quran` | `surah`, `ayah_from`, `ayah_to` | Official Uthmani text from the KFGQPC data, with the reference. |
| `hadith` | `record_id` | HadeethEnc text, grade (as given) and references. |
| `question` | `prompt`, `options`, `answer` (index) | A quiz question; answering marks progress. |
| `check` | `body` | A text with a button that sends it to the verifier. |

Progress (completed lessons and answered questions) is saved only in the visitor's browser (localStorage). There are no accounts and we store nothing.
